# Css

## Tailwind CSS como sistema visual
Usa Tailwind CSS 4 con configuración CSS-first en resources/css/app.css. Define colores, tipografías, tamaños y breakpoints propios mediante @theme; no introduzcas tailwind.config.js salvo necesidad explícita de una dependencia.

## Tailwind como primera opción de estilos
Usa Tailwind para estilos utilitarios y componentes siempre que sea suficiente. Reserva Sass para overrides o comportamientos especiales de librerías y componentes que requieran CSS propio.
